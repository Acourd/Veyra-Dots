# NothingZen Minimalist Wallpapers 4K — Edición OLED & Chalk (3840×2160)

Colección de **30 fondos de escritorio planos (2D vectorial nativo 4K)** inspirados en **Nothing OS**, diseñados específicamente para tu layout limpio de widgets **NothingZen** (columnas laterales libres de ruido y centro despejado):

- **Modo Oscuro OLED (`modo-oscuro-oled/`):** negro profundo tipo OLED con capas grafito/tintadas de contraste equilibrado.
- **Modo Claro Chalk (`modo-claro-chalk/`):** papel mate cálido estilo *Chalk* para integrarse de forma natural con los widgets claros.
- **5 acentos exactos del selector NothingZen:** `rojo`, `amarillo`, `azul`, `verde` y `monocromo`.

## 3 estilos por cada color y modo
1. `monolito`: Geometría industrial plana con bloques inclinados, disco focal punteado y punto de acento Nothing.
2. `orbita`: Discos concéntricos planos, anillo de 60 micro-puntos y arco *Glyph* escultórico centrado.
3. `halftone`: Cápsulas diagonales planas con lente circular de matriz de puntos (*dot-matrix*) contenida en el centro.
