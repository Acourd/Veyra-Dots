# Tema: macOS (Sonoma / Sequoia Style)

Suite nativa de Rainmeter sin plugins externos inspirada en **macOS Sonoma / Sequoia**: tarjetas esmeriladas (*frosted glass*) con bordes especulares finos, modos **Oscuro Sequoia / Claro Sonoma**, **6 acentos Apple HIG + Auto Wallpaper**, barra superior flotante, Centro de Control, Apple Notes y Activity Rings.

## Widgets incluidos (`MacOSZen`, 28 widgets)

| Categoría | Widgets |
| :--- | :--- |
| **ThemeSwitcher (1)** | `MacOSSwitcher.ini` — Alterna en 1 clic entre **Oscuro / Claro**, **ES / EN**, **6 acentos Apple HIG** (`Blue`, `Purple`, `Pink`, `Orange`, `Green`, `Graphite`) y **Auto Wallpaper**. |
| **ProHub (3) — Subsección Productividad & Hardware** | `MacOSBluetoothHub.ini` (dispositivos Bluetooth conectados/emparejados + batería), `MacOSAIUsageHub.ini` (consumo diario de ChatGPT, Claude, Gemini y Grok con iconos HD) y `MacOSStorageVault.ini` (bóveda multi-unidad SSD/USB en vivo). |
| **Menu Bar (1)** | `MacOSMenuBar.ini` — Píldora superior flotante estilo Menu Bar con fecha, hora, CPU, batería y cambio rápido de modo. |
| **Clock (5)** | `MacOSAnalogClock.ini`, `MacOSWorldClock.ini`, `MacOSSolarClock.ini` (arco solar/lunar orbital), `MacOSStandByClock.ini` (reloj gigante de fichas partidas estilo StandBy) y `MacOSGreetingHero.ini` (cabecera tipográfica estilo pantalla de bloqueo). |
| **Calendar (2)** | `MacOSCalendarDay.ini` (cuadrado icónico con acento dinámico) y `MacOSCalendarMonth.ini` (mes 6×7 con círculo de acento en hoy). |
| **Battery (1)** | `MacOSBatteryRing.ini` — Anillo circular verde Apple con rayo de carga y alerta roja bajo 20%. |
| **System (5)** | `MacOSActivityRings.ini` (3 anillos concéntricos Apple Activity), `MacOSiStatHub.ini` (dashboard estilo iStat Menus), `MacOSAboutStorage.ini` (barra segmentada estilo Acerca de este Mac), `MacOSNetSpeed.ini` (velocímetro de red bajada/subida) y `MacOSPowerMenu.ini` (menú Apple de sesión: Ajustes, Bloquear, Suspender, Reiniciar). |
| **Control Center (1)** | `MacOSControlCenter.ini` — Accesos rápidos a Wi-Fi, Bluetooth, Modo Oscuro/Claro, Silencio y deslizador interactivo de volumen. |
| **Notes & Reminders (2)** | `MacOSNote.ini` (franja amarilla clásica de Apple Notes editable al hacer clic) y `MacOSReminders.ini` (lista interactiva con botón `+`). |
| **Music (2)** | `MacOSMusic.ini` (reproductor horizontal estilo Apple Music) y `MacOSMusicMini.ini` (tarjeta cuadrada 2×2). |
| **Search & Dock (3)** | `MacOSSpotlight.ini` (búsqueda flotante `⌘ K`), `MacOSDock.ini` (dock esmerilado con 6 apps HD) y `MacOSAIBar.ini` (5 asistentes de IA HD). |
| **Productivity (2)** | `MacOSFocus.ini` (Pomodoro circular de 25 min) y `MacOSNotchHub.ini` (cápsula flotante estilo Dynamic Island / NotchNook con música, CPU y batería). |

## Instalación rápida

```powershell
.\scripts\install-rainmeter.ps1 -Theme macos
```
