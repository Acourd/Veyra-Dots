# Veyra-Dots — Samsung One UI Flat Vector Wallpapers 4K (3840×2160)

Colección de **36 fondos de escritorio planos (2D vectorial nativo 4K)** diseñados para `Acourd/Veyra-Dots`, inspirados en el lenguaje visual de **Samsung One UI 6 / One UI 7** (curvas S, squircles concéntricos y prismas geométricos con contrastes profundos para OLED y superficies claras limpias).

## Estructura
- `modo-oscuro/`: 18 fondos 4K (gris, azul, rojo, rosado, amarillo y verde).
- `modo-claro/`: 18 fondos 4K (gris, azul, rojo, rosado, amarillo y verde).

## 3 estilos por cada color y modo
1. `scurva`: Cinta estilizada en curva "S" inspirada en Galaxy S25 / One UI 7.
2. `squircle`: Superelipses concéntricas (la silueta característica de One UI) con espacio libre a la izquierda para widgets.
3. `prisma`: Planos geométricos diagonales y círculos translúcidos inspirados en Galaxy S24 / One UI 6.
